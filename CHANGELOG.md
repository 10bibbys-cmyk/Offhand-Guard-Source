# Changelog

## 1.0.0.1
- Removed repeated console logging for prevented offhand actions.
- Preserved the existing offhand protection logic, interaction handling, and Mixin targets.
- Updated version and release metadata.

## 1.0.0 — Initial release
- Fixed offhand items disappearing in Survival when casting RMB-bound spells while holding two-handed Better Combat weapons.
- Prevented unintended client-side and server-side offhand item use and offhand clearing.
- No custom configuration, commands, or gameplay balance changes.
- Tested with Better Combat 1.8.6 and Spell Engine 0.15.12.

### Public source snapshot
- Reconstructed source from the previously released 1.0.0 production JAR.
- Added reproducible build files and an All Rights Reserved notice for subsequent source distributions.
